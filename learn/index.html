A simple order to follow

  1. Start with Speak English. It builds the habit of talking out loud, which the other two books rely on.
  2. Then do Grammar, so the sentences you say are built correctly.
  3. After that, do Vocabulary, then Prepositions. Each one gives you more to say in the speaking tasks.
  4. Run HSK1 alongside whichever English book you're on. It's a different language and a different part of the day, so the two don't compete.
  5. Missed a day? Carry on from where you stopped. Don't do two days at once.

Progress is saved in this browser only. If you switch phone or computer, it starts again there.
